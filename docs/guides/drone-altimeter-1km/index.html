What to check

  • Datasheet ranges are usually quoted for a large, high-reflectance target (often 90% whiteboard or a building) in good visibility. Grass, crops, water and snow return less light, so the usable altitude over terrain is normally well below the headline number; check the range condition column.
  • Update rate matters for terrain following: a 1-10 Hz long-range module suits survey altitude hold, while landing and obstacle work usually needs 50 Hz or more at short range.
  • Check how the flight stack will read the sensor: the driver column lists open-source drivers (ArduPilot, ROS 2, Arduino) that name the exact model; others need a companion computer or a custom driver using the manufacturer's protocol document.
