What to check

  • I2C labels do not establish plug compatibility. Confirm supply and logic voltage separately, address selection, pull-up requirements, register map and the exact ordered interface variant.
  • The interface filter includes modules intended for different media and target conditions. Read the range condition before comparing rows; an underwater specification is not an air rating.
  • A listed driver names a particular model; an empty driver field is not proof that no driver exists. No electrical limits, range values or compatibility claims have been inferred. Request prices from each maker; this page does not list them.
