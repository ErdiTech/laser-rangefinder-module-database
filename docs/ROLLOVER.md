# Annual rollover

Run `python scripts/build_views.py` after the year changes, then validate and review the generated diff.
Titles, descriptions and headings on comparison, guide and alternatives pages use the system year.
Manually recheck source links, discontinued products and every recommendation before publishing.
Updated/dateModified/lastmod follow the latest committed change to modules.json or the shared
page generator/helpers, never the build date. Git history is required; checkouts must retain it.
A shared template change legitimately affects all pages. Data capture dates remain separate.
The best page is a transparent shortlist from existing data, not a hands-on review.
