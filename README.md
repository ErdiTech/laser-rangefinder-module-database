# Laser rangefinder module database

An open, manufacturer-sourced dataset for choosing a **laser rangefinder module / single-point LiDAR**: range together with the target condition it is quoted for, wavelength (905 / 1535 nm), accuracy, update rate, interface (UART, I2C, CAN, RS-422), weight, public price and open-source drivers, with the source link and capture date on every row.

**[Open the sortable, filterable table](https://erditech.com/laser-rangefinder-module-database/)** · <!-- nmod -->165<!-- /nmod --> rangefinder modules (<!-- count -->179<!-- /count --> rows incl. scanning units and laser sources) · data updated <!-- date -->2026-11-17<!-- /date --> · [CSV](data/modules.csv) · [JSON](data/modules.json) · [add a module](#add-or-correct-a-module)

Maintained by ERDI TECH LTD ([erdilrf.com](https://erdilrf.com/)), which also makes some of the listed modules. Every manufacturer's rows follow the same rules: values copied from the maker's own page or datasheet, nothing estimated, `null` when the maker does not publish a value.

## Schema

| Field | Meaning |
|---|---|
| `brand`, `model` | As written by the manufacturer |
| `category` | `rangefinder module`, `scanning rangefinder`, or `laser source (component)` (pulsed emitters sold for building rangefinders; no range spec) |
| `wavelength_nm` | Laser wavelength (850/905/940 nm = silicon-detector class, 1535/1550 nm = eye-safe InGaAs class) |
| `min_range_m`, `max_range_m` | Published range limits in metres |
| `range_condition` | Target size, reflectance and visibility for `max_range_m`. A range without its condition is not comparable |
| `max_range_special_m`, `max_range_special_condition` | A higher published range under a stated special condition |
| `accuracy`, `rate_hz`, `interface`, `voltage`, `dimensions`, `laser_class` | Verbatim strings, because makers quote them differently |
| `weight_g` | Grams |
| `price_public_usd` | Single-unit USD price on the maker's own site; `null` if it only quotes |
| `price_volume_usd`, `price_volume_min_qty` | Largest published volume tier |
| `open_source_drivers` | Open-source drivers that name this exact model: list of `{name, url}` |
| `status` | `active`, `discontinued` or `unknown`, as shown on the source |
| `product_url`, `source_url` | Product page, and the page or PDF the values were copied from |
| `captured_at` | Date the source was read |
| `notes` | Optional caveats, e.g. inconsistencies inside a source |

`null` means the manufacturer does not publish the value, not that the module lacks it.

## Quick start

```python
import pandas as pd
df = pd.read_csv("https://erditech.com/laser-rangefinder-module-database/data/modules.csv")
km = df[(df.max_range_m >= 1000) & (df.weight_g <= 30)]
print(km.sort_values("weight_g")[["brand", "model", "wavelength_nm", "max_range_m", "range_condition", "weight_g", "price_public_usd"]])
```

```bash
python query.py --min-range 1000 --interface UART          # long-range UART modules
python query.py --wavelength 1535 --max-weight 50 --format csv
python query.py --has-driver --max-range 100                # short-range modules with an open-source driver
python -m pytest -q                                         # data validation + query tests
python scripts/build_views.py                               # regenerate CSV, MODULES.md and the site
```

## Add or correct a module

Pull requests are welcome from anyone, including competing manufacturers.

**In scope:** single-point laser / ToF distance modules sold as integrated units with their own protocol (UART, I2C, CAN, RS-422, RS-485, PWM), single-beam scanning rangefinders, and pulsed laser sources sold for building rangefinders. **Out of scope:** bare ToF-chip breakout boards (VL53L0X-type), multi-beam / 3D LiDAR, radar altimeters, and finished handheld rangefinders.

Rules:

1. Values must come from the **manufacturer's own** product page or datasheet (no reseller listings, forum posts or estimates). Copy strings verbatim; use `null` for anything not published.
2. Put the page you copied from in `source_url` and today's date in `captured_at`.
3. Run `python scripts/validate.py` and `python scripts/build_views.py`, then commit the regenerated files.

Template row for `data/modules.json`:

```json

  "brand": "Example Corp",
  "model": "XR-1000",
  "category": "rangefinder module",
  "wavelength_nm": 905,
  "min_range_m": 3,
  "max_range_m": 1000,
  "range_condition": "2.3 m x 2.3 m target, 90% reflectance, visibility 10 km",
  "max_range_special_m": null,
  "max_range_special_condition": null,
  "accuracy": "±1 m",
  "rate_hz": "1-10 Hz",
  "interface": "UART (3.3 V TTL)",
  "voltage": "5 V DC",
  "weight_g": 12,
  "dimensions": "25 x 21 x 13 mm",
  "laser_class": "Class 1",
  "price_public_usd": null,
  "price_volume_usd": null,
  "price_volume_min_qty": null,

}
```

Found a wrong value or a dead link? Open an issue with the model and the manufacturer link, or send the fix as a PR.
