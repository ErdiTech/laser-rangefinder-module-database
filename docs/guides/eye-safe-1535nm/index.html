What to check

  • 1535/1550 nm light is absorbed before it reaches the retina, so IEC 60825-1 allows far more pulse energy at these wavelengths than at 905 nm for the same laser class. That is why multi-kilometre Class 1 modules are almost all 1.5 µm designs.
  • The trade-off is cost and size: 1.5 µm modules need an InGaAs detector and usually an erbium-glass laser, so they cost and weigh more than 905 nm modules of similar short-range performance. The laser class actually certified for a given module is in its datasheet; the laser_class column is empty where the maker does not publish it.
  • Most long-range 1535 nm modules use RS-422 or 3.3 V TTL UART and update at 1-10 Hz.
